# GenAI Cookbook

A practical resource for learning, building and mastering Generative AI applications from the ground up.

## What's Inside?

- **100 Interview Questions:** From fundamentals to advanced system architecture.
- **Hands-on Projects:** Multimodal RAG, Agentic AI and Computer Use Agents.
- **Core Concepts:** LLMs, embeddings, vector databases, memory, fine-tuning, inference and observability.
- **Production Engineering:** Scalability, evaluation, security and optimisation.

## Philosophy

Understand the fundamentals before relying on abstractions. Focus on how GenAI systems actually work, not just how to use frameworks.

**Learn. Build. Experiment. Master.**
