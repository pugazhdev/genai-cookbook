# GenAI Cookbook

A practical resource for learning, building and mastering Generative AI applications from the ground up.

## What's Inside?

- **100 Interview Questions:** From fundamentals to advanced system architecture, each with a short hint answer.
- **Hands-on Projects:** Multimodal RAG, Agentic AI and Computer Use Agents.
- **Core Concepts:** LLMs, embeddings, vector databases, memory, fine-tuning, inference and observability.
- **Production Engineering:** Scalability, evaluation, security and optimization.

## How to Use

Everything lives in a single static page, `index.html`. Open it in a browser or host it on any static host (GitHub Pages, Netlify, S3). No build step or backend needed.

- **Questions tab:** 10 topics, one per page. Try answering each question out loud, then click it to reveal the hint.
- **Projects tab:** Ground rules, assessment criteria and three projects to build by hand.

Each page has its own link (for example `#q3` or `#p2`), so you can share a specific topic directly.

## Philosophy

Understand the fundamentals before relying on abstractions. Focus on how GenAI systems actually work, not just how to use frameworks.

**Learn. Build. Experiment. Master.**
